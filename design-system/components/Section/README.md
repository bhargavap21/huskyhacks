A page section: serif heading, one lead line that names the source, then an ordered list split by hairlines.

Markup: `<section class="in-section">` with `<h2 class="in-section__heading">`, `<p class="in-section__lead">` and `<ol class="in-ol">`.

- The consumer provides the heading, the lead and the list items. Each item opens with a short claim, then one explaining sentence.
- Numerals are generated by CSS in `ink-muted`; do not type them.
- Separate sections with `space-8` of whitespace. Never wrap a section in a card or draw a rule between sections.
- Use the lead to state caveats ("not verified", "themes, not quotes").
